# Hello World 网站（Node.js）

我是 yangjingren，这是我第一个 AI 协助开发的 Node.js 网站。

## 功能
- 浏览器访问显示：「Hello World！我是yangjingren，我的第一个AI开发的网站」
- 页面同时显示服务器当前时间（Asia/Shanghai）

## 运行方式
```bash
node index.js
# 或
npm start
```

访问：http://127.0.0.1:3000
